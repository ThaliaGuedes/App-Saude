# App Saúde

## Descrição do Projeto
O **App Saúde** é um aplicativo web desenvolvido para facilitar o acesso da população a informações e serviços de saúde oferecidos por unidades municipais. O sistema permite visualizar histórico de saúde, agendamentos, vacinas, medicamentos, serviços e ouvidoria de forma simples e intuitiva.  

O projeto foi desenvolvido utilizando **Python** com **Flask** para o backend e HTML/CSS/JavaScript para o frontend.

---

## Funcionalidades
- Visualização do histórico de consultas e exames.
- Consulta de próximos agendamentos.
- Acesso à carteira de vacinação.
- Informações sobre unidades de saúde e serviços disponíveis.
- Consulta de medicamentos disponíveis.
- Comunicação com a ouvidoria.
- Interface adaptada para visualização em dispositivos móveis.

---

## Tecnologias Utilizadas
- Python 3.x
- Flask
- HTML5 / CSS3 / JavaScript
- Font Awesome (para ícones)
- Render ou GitHub Pages para hospedagem
